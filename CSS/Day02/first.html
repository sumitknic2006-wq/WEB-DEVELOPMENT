A Virtual Machine (VM) is a software-based version of a physical computer. It provides an environment in which programs can run as if they are running on a real machine. In Java, the Java Virtual Machine (JVM) is responsible for executing Java programs.

Suppose a Java program is written on a Windows computer. After compilation, the generated bytecode can run on any operating system that has a JVM installed, such as Windows, Linux, or macOS.
